Install

  1. Turn the clock on: hold < and > for 3 seconds.
  2. Connect it to this computer with a USB cable.
  3. Open this page in Chrome or Edge, then select Connect.
  4. Join the nsclock Wi-Fi network on your phone and open http://192.168.4.1/ to set it up.

If no new reading arrives for 15 minutes, the clock restarts itself and signs in again.
